## Task 1: Add `$defs/contract` to the skill-metadata schema

- ACM row 1 (issue #1965): "`spec.contract` is expressible in the sidecar
  schema".
- Quoted Planned ops, verbatim from issue #1965 (Proposed solution 1):
  "add `$defs/contract` (precondition, goal, invariants, gates,
  escalation, handoff; `additionalProperties: false`; each `gates[]`
  entry is `{id, plane, shipped}`; `handoff` carries `downstream`) wired
  as optional `spec.contract`; add one sentence to the top-level
  description stating that `spec.contract` is the one block projected
  into `SKILL.md` at build time; leave the lifecycle block's runtime-read
  invariant unchanged." Structure: `precondition[]` is
  `{id, check, onFail}` with `id` on the `skillNameRef` pattern; `goal`
  is `{endState, check, constraints[]}`; `invariants[]` is
  `{text, gate}` with `gate` a string or `null`; `gates[]` is
  `{id, plane, shipped}` (`plane` enum: ci, local, pretooluse,
  posttooluse, stop); `escalation[]` is `{when, to}`; `handoff` is
  `{next: {skill, fallback, carries}, inline[], optional[], downstream}`
  with every skill name a `skillNameRef`. Required keys:
  `goal.endState`, `goal.check`, `handoff.next.skill`. Every prose field
  (`precondition[].check`, `goal.endState`, `goal.check`,
  `goal.constraints[]`, `invariants[].text`, `escalation[].when`,
  `handoff.next.carries`, `handoff.downstream`) is `minLength: 1`,
  `maxLength: 200`, rejects an embedded newline. `precondition[].onFail`
  and `escalation[].to` are free kebab-case strings (pattern only) until
  PR3.
- Precedent confirmed this session: `$defs/referenceItem` (array-of-
  records shape), `$defs/skillNameRef` (kebab-case pattern), `$defs/
  toolTagList` ("empty array is a deliberate zero declaration" doc
  convention) in `skills/evaluating-skill-quality/references/skill-
  metadata.schema.json`.
- Files:
  - Edit: `skills/evaluating-skill-quality/references/skill-metadata.schema.json`
  - Edit: `tests/test_gitapex_scan_skill_metadata_schema.py`
- Steps:
  1. Add `$defs/contract` with the six blocks per the shape above,
     `additionalProperties: false`.
  2. Wire `spec.contract` as optional in the top-level `spec` schema.
  3. Add one sentence to the schema's top-level `description` stating
     `spec.contract` is the one block projected into `SKILL.md` at build
     time. Do not touch the lifecycle block's runtime-read invariant
     sentence.
  4. Add fixture test cases: a full valid `spec.contract` passes; an
     unknown key under `contract` fails; a 201-character `goal.check`
     fails; an embedded newline in `invariants[].text` fails; an
     out-of-enum `gates[].plane` fails; a missing `handoff.next.skill`
     fails.
- Proof method: `tests/test_gitapex_scan_skill_metadata_schema.py` passes
  on all 29 existing sidecars plus the new fixture positive/negative

- Irreversibility: reversible (schema addition, additive only).
