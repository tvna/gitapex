# scanning-leaked-secrets: Implementation Plan

**Goal:** Ship `skills/scanning-leaked-secrets/`, wrapping `betterleaks`
(already SHA256-pinned in `flake.nix` v1.6.1) as the `scanning-*`
family's second shipped skill -- scanning a target repository's working
tree and history for leaked secrets, redacting every literal secret value
before it reaches this skill's own report. Source:
https://github.com/tvna/gitapex/issues/849.

**Architecture:** One new skill directory (`SKILL.md`,
`metadata/gitapex.yaml`, `references/worked-examples.md`), one new eval
corpus (`evals/scanning-leaked-secrets/`), and one documentation
correction whose existing text is stale independent of this change. No
`flake.nix` edit (betterleaks is already pinned) and no `scripts/`
directory (betterleaks' own CLI flags cover the full Requested Outcome
with zero wrapper code).

**Tech Stack:** Plain Markdown + YAML. No new Python, no new dependency.
