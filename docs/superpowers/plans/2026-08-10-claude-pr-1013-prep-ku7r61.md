## Task 4 -- `gitapex_gate_split_fixture_coverage.py`: JSON-read wrap, double-read dedup, triple-union dedup

**Cites ACM rows:** "Hand-rolled JSON-read pattern ..." (row 1,
`gitapex_gate_split_fixture_coverage.py:199` sub-item); "...
`gitapex_gate_split_fixture_coverage.py:373` each stop double-reading the
same file per run" (row 8, this file's half); "`...:564`'s triple `union()`
computed once" (row 9).

**Quoted Planned ops (verbatim):** "Replace each hand-rolled block with a
call to the shared helper..." (row 1, adapted below since this file's
`load_split_json` returns a tuple rather than raising -- see step 1);
"Compute the per-skill map once, pass/reuse it at both call sites instead
of a second glob+load" (row 8); "Compute once immediately after building
`listed`, reuse at the three existing call sites" (row 9).

**Files:** `.github/scripts/gitapex_gate_split_fixture_coverage.py`.

**Steps:**
1. `load_split_json` (lines 199-220) returns `tuple[dict | None, str |
   None]`, not a raise -- `load_json_or_raise` cannot be swapped in
   directly without changing every call site's calling convention. Wrap
   it instead: call `load_json_or_raise(path, _SplitLoadError)` (a small
   local exception) inside a `try/except`, converting a raised error into
   the `(None, message)` tuple this function's callers already expect.
   The existing `path.is_file()` pre-check can be dropped -- `OSError`
   (which `load_json_or_raise` already catches) covers a missing file via
   `FileNotFoundError`, one of its subclasses.
2. `check_precedence_branch_coverage` (Check B, ~line 373) independently
   loads a skill's `split.json` via `load_split_json`, and Check C
   (~line 680) loads the same path again for any `--skill-md` file whose
   sibling `split.json` exists -- `exercises_checked` dedups Check C
   against a same-run `split.md` load but never against Check B's own
   load. Compute a per-path `split.json` cache (a plain `dict[Path,
   tuple[dict | None, str | None]]` populated on first load) once per
   `main()` run, and have both Check B and Check C read through it
   instead of calling `load_split_json` independently.
3. `check_partition_arithmetic` (~line 564) recomputes
   `set().union(*listed.values())` independently at three call sites
   (568, 576, 586). Bind it once to `all_listed` immediately after
   `listed` is built, and reuse that binding at all three sites.
4. Run this file's own existing test suite, full pass; optionally assert
   the per-path cache is populated once, not twice, for the double-read
   fix (matching the issue's own suggested proof method).

**Proof method:** existing test suite, full pass; new/adjusted assertions
for the wrapped JSON-read error path and the single-load cache behavior.

## Post-task gate (Decision 12, mandatory)

After all 13 tasks land: one refactor/simplify pass (behavior-preserving
only) and one independent adversarial code review, each a fresh subagent
dispatch over the full accumulated diff. Every CONFIRMED finding is fixed
and every task's own Red-Green test is re-run (not only the one related to
the fix) before the draft PR converts to ready-for-review.
